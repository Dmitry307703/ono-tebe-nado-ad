# Оно тебе надо

Учебный проект: одностраничный сайт аукциона необычных вещей.

Репозиторий проекта: https://github.com/Dmitry307703/ono-tebe-nado-ad

## Структура

- `index.html` — разметка страницы: шапка, обложка, лоты, секция «Об аукционе», подвал.
- `styles/global.css` — базовые стили и ширина контента.
- `styles/style.css` — стили секций.
- `fonts/fonts.css` — подключение шрифта Raleway.
- `images/` — изображения обложки, карточек лотов, логотипы и иконки соцсетей.
